# 角色人设标签格式

## 名称与占位符

- `char` 不使用占位符。先确定角色名称，并在正文中直接写真实名称，例如「禾安」。
- 玩家只使用 `{{user}}`，不要写死玩家姓名。
- 禁止继续使用 `$#char#$`、`$#user#$`、`{{char}}` 或「角色名」这类替代写法。
- 用户没有提供角色名时，根据设定补一个贴合世界观、可直接使用的名称；不要停在占位符状态。

## 标签规则

使用截图式的单行章节标签组织内容：

```text
<世界观>
这里写世界核心设定。
</世界观>

<角色设定 名字：禾安>
<基本信息>
- 年龄：24 岁
- 身份：种子铺守护人
</基本信息>

<与{{user}}的关系>
禾安与{{user}}从农场伙伴开始建立关系。
</与{{user}}的关系>
</角色设定>
```

标签只负责划分章节，遵循以下规则：

1. 开始标签和闭合标签都独占一行，使用全角或半角冒号均可；推荐全角冒号。
2. 每个开始标签必须有同名闭合标签，例如 `<世界观>…</世界观>`、`<道具>…</道具>`。
3. 角色主标签必须写成 `<角色设定 名字：真实角色名>`，并用 `</角色设定>` 闭合；闭合标签不重复名字属性。
4. 子章节写在所属外层标签内部，必须按后开先闭的顺序正确嵌套，不能交叉闭合。
5. 同一层级的标签名称保持稳定，不要一会儿叫「背景」、一会儿叫「往事」。
6. 原子信息用 `- 字段：内容`；氛围、关系与行为逻辑可用短段落。
7. 标签内容是自然语言设定，不放 HTML、CSS、脚本或 SDK 调用。

## 推荐顺序

按需求选用，不需要为了凑格式保留空章节：

```text
<世界观>
世界核心设定。
</世界观>

<历史背景>
历史与时间线。
</历史背景>

<地图>
地点与区域。
</地图>

<角色设定 名字：真实角色名>
<基本信息>
身份与职责。
</基本信息>
<与{{user}}的关系>
起始关系与边界。
</与{{user}}的关系>
<性格特点>
稳定性格。
</性格特点>
<说话方式>
语言与语气。
</说话方式>
<外貌特征>
可见外貌。
</外貌特征>
<背景设定>
经历与动机。
</背景设定>
<道具>
影响剧情的物品。
</道具>
<能力与限制>
能力边界。
</能力与限制>
<行为逻辑>
决策顺序。
</行为逻辑>
</角色设定>

<养成规则>
成长与资源规则。
</养成规则>
```

世界书条目合并进 `personality` 时也使用同样的标签。例如：

```text
<补充世界设定>

<风铃镇>
- 定位：青芽谷的中心聚落。
- 规则：居民只知道自己合理接触到的信息。
</风铃镇>

</补充世界设定>
```

不要改回 `【世界观】` 或 Markdown 标题。不要遗漏闭合标签，也不要写成 `<世界观>…</地图>` 这类名称不匹配的结构。
