# 角色卡制作手册

写给做卡的人。你在创卡页能填的，跟界面有关的只有一处：**正则替换规则的「替换内容」**。HTML、`<style>`、`<script>` 都写在那里。

功能栏（聊天页顶部下面那一条）来自角色卡的 `statusbar` 字段，同样会过一遍你的规则。常见写法：`statusbar` 里只放 `{{hud}}`，真正的界面写在规则里。

## 一条规则怎么写

一条规则三样东西：**名称**（给你自己看）、**匹配式**（要被换掉的那段字）、**替换内容**（换上去的东西）。

匹配式两种写法：

| 你填的 | 平台怎么理解 |
| --- | --- |
| `【图鉴】`、`{{hud}}` | 就照这几个字**原样找**，全文每处都换。多数规则都这么写 |
| `/血量[:：]\s*(\d+)/` | 两边加斜杠才当**正则**用。自动全文替换，`g` 不用自己加 |

写成 `/…/` 但斜杠里的正则有语法错，这条规则会被整条跳过（页面上看不出异常，只有告警）。不确定就用第一种。

替换内容里可以取值：

| 记号 | 意思 |
| --- | --- |
| `$1`、`$2` | 正则里第 1、2 个括号捕获到的内容 |
| `$名字` | 第一个括号捕到的是 `血量::10;;金币::3` 这种成对写法时，`$血量` 就取到 `10` |
| `{{random:甲::乙::丙}}` | 三个里随机一个 |

例：AI 写「血量：70」，页面上出现一根 70% 的血条。

```html
<!-- 匹配式：/血量[:：]\s*(\d+)/ -->
<div class="my-hp" style="width: $1%; height: 8px; background: var(--chat-accent);"></div>
```

## 照着做一遍：功能栏上加一条血条

1. 卡片的 `statusbar` 字段填 `{{hud}}`（就一个占位词，真东西写在规则里）
2. 加一条规则：名称 `hud`，匹配式填 `{{hud}}`，替换内容贴下面这段
3. 回聊天页看效果

```html
<div class="my-hud">血量 <span class="my-bar" style="width: 70%"></span></div>
<style>
.my-hud { padding: 6px 10px; font-size: 13px; color: var(--chat-text); }
.my-bar { display: inline-block; height: 8px; border-radius: 4px; background: var(--chat-accent); }
</style>
```

同一条规则里可以 HTML、`<style>`、`<script>` 混着写。完整能跑的一张卡：[`example-card/card.json`](example-card/card.json)。

## 五条先记住

1. **规则对这张卡的每条 AI 消息都生效**，不是只作用在你测的那一条。匹配式写得太松（比如只写一个 `：`）会把正常对话切碎。
2. **脚本整张卡只跑一次。** 给每条气泡绑按钮，写在 `sdk.on('message:mount')` 里。
3. **`<style>` 和 `<script>` 不论这条规则有没有匹配到，都会装上**（它们在装卡时就被抽出来了）。所以别靠「不命中」来关样式；反过来也可以专开一条规则只放脚本。
4. **你自己写的 `data-*` 会被删掉。** 自己的按钮用 class 或 id。`[data-chat="…"]` / `[data-slot="…"]` 是平台页面上的，你可以拿来当选择器。
5. **替换内容会过一遍 Markdown。** 别把 HTML 缩进四个空格，那会被当成代码块原样显示。

## 出问题先看这里

- **改了整页背景，底栏、输入框或弹窗没变。** 它们有独立的 18 个扩展变量，见[第 1 章「改底栏和弹窗颜色」](01-style.md#改底栏和弹窗颜色)。仅支持白名单弹窗；2026-09-05 在线文档已把“记忆管理”列入该范围，若实际仍未变色，按[主题桥诊断](../references/host-theme-bridge.md)核对目标站版本、父层变量映射和最终计算颜色。


- **点了发送 / 选项，画布上出现「消息生成中」，stream 已经在吐字。** 空 AI 气泡一挂上，`message-body` 就是这句占位。不要在 `message:mount` 里读它当回复；跟字用 `message:stream` 的 `msg.content`，收尾用 `message:done`。见[第 2 章](02-script.md)「别把「消息生成中」当回复」。
- **按钮点了没反应。** 绑事件写到脚本顶层了。气泡滚出屏幕会被拆掉，要写在 `sdk.on('message:mount')` 里，见[第 2 章](02-script.md)。
- **同一件事触发了好几次。** `sdk.on` 写进 `message:mount` 里了。订阅写在脚本体，一次就够。
- **我写的 `data-xxx` 不见了。** 净化会删掉自己写的 `data-*`。用 class 或 id。
- **事件一次都不触发。** 事件名写错了不会报错。照[第 4 章](04-sdk.md)的名单抄。
- **样式在预览里对，上线不对。** 别的规则也带了 `<style>`，而所有规则的样式都会装上，后写的盖住先写的。
- **画的东西滚一会儿就没了。** 挂在气泡里的东西会随气泡销毁。要一直在的，挂舞台，见[第 2 章](02-script.md)。
- **预览里调什么都报 `NOT_SUPPORTED`。** 创卡页的预览是简化环境，输入框、发送、存档都不开放。回聊天页验。
- **手机上看不到报错。** 聊天页 URL 加 `?sdkDebug=1`，用 `sdk.debug.log` 打日志。你的脚本报错、外链没加载上，也都写在那块面板里。
